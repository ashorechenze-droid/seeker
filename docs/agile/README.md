# SimpleRAG 敏捷开发证据

本目录记录从需求优先级到迭代验收的可追踪过程。历史功能只根据已有 Git、`plan.md`、ADR 和测试证据整理，不补写不存在的站会或评审参与者。

## 文档入口

- `PRODUCT_VISION.md`：产品目标、用户和范围。
- `PRODUCT_BACKLOG.md`：用户故事、优先级、故事点、状态和验收证据。
- `DEFINITION_OF_DONE.md`：所有故事完成时必须满足的共同条件。
- `sprints/`：每个 Sprint 的目标、范围、任务、风险和验收标准。
- `reviews/`：迭代结束时的客观演示与测试结果。
- `retrospectives/`：问题、原因和下一次可验证改进行动。

## 工作方式

1. Product Backlog 是需求状态的主记录。
2. Sprint 开始时选择少量用户故事并冻结 Sprint Goal。
3. 实现期间同步维护代码、测试、ADR/架构文档和需求追踪矩阵。
4. Review 只记录已经演示或自动验证的结果。
5. Retrospective 至少产生一项有负责人和完成条件的改进行动。
